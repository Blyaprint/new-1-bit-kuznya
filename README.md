# 1-Bit Dungeon Card Battler

Fresh Godot 4.6 project branch: `fresh/1bit-card-battler`.

## Run
Open this repository in Godot 4.6 and run the main scene configured in `project.godot` (`scenes/battlefield.tscn`).

## Current state
The project contains a first battlefield UI wireframe at a 640×360 logical resolution. The screen is divided into a 36 px top strip, 252 px battlefield, and 72 px hand area. The sample cards and scores are layout placeholders.

## Art rule
Final art is to be hand-drawn manually in a pixel editor and imported as separate raster assets. Do not create final sprites or illustrations with code. The only palette colors are pure black and pure white.
